
# Computer Vision Mini Project – Face Detection System

## Technologies Used
- Python
- OpenCV
- Flask (Backend API) (need to run diff terminal)
- Streamlit (Frontend UI) (need to run diff terminal)

## Features
- Upload an image
- Detect human faces
- Display face bounding boxes

## How to Run
1. pip install -r requirements.txt
2. python app.py
3. streamlit run ui.py
